# Frequently Asked Questions (FAQ)

## General

**Q: Where is the API documentation?**
A: It is generated by Swagger and available at `/api` when the server is running.

**Q: How do I reset the database?**
A: Run `docker-compose down -v` followed by `docker-compose up -d`. **Warning**: This deletes all data!

## Development

**Q: Why are my changes not reflecting?**
A: Ensure you are running `npm run start:dev` (watch mode). If you changed `.env`, restart the server manually.

**Q: How do I add a new Module?**
A: Use the Nest CLI: `nest g module modules/my-feature`.

## Deployment

**Q: Where are the logs stored in production?**
A: Logs are sent to `stdout` and collected by our logging driver (e.g., AWS CloudWatch or ELK Stack).

**Q: How do I SSH into the production server?**
A: SSH access is restricted. Use the AWS SSM Session Manager or similar secure tools.
