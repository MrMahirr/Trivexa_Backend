# Finance Guide

Guide for managing the financial aspects of Trivexa Projects.

## 1. Project Finance

### 1.1 Setting Budgets
1.  Open Project > **Settings**.
2.  Set **Budget Type**: `Fixed Price` or `Hourly`.
3.  Enter **Total Budget** amount.
4.  The system will alert you when 80% of the budget is consumed.

## 2. Invoicing

### 2.1 Creating an Invoice
1.  Go to **Finance > Invoices**.
2.  Click **"New Invoice"**.
3.  Select Client and Project.
4.  **Add Line Items**:
    - *Manually*: Add description and amount.
    - *From Timesheets*: Click "Import Unbilled Hours".
5.  **Save as Draft**.

### 2.2 Sending to Client
1.  Review the Draft.
2.  Click **"Send"**.
3.  The client receives an email with a secure payment link.

### 2.3 Recording Payments
- **Automatic**: Stripe/PayPal payments are recorded instantly.
- **Manual**: If paid via Bank Transfer, click **"Record Payment"** and enter the transaction ID.

## 3. Expenses

### 3.1 Logging an Expense
1.  Go to **Finance > Expenses**.
2.  Upload Receipt (Image/PDF).
3.  Enter Amount and Category (e.g., Software License, Travel).
4.  Link to a Project (if billable to client).

### 3.2 Reimbursements
- Expenses marked as "Reimbursable" are flagged for payroll processing at the end of the month.

## 4. Financial Reports

- **Profit & Loss**: Revenue vs Expenses per Project.
- **Aging Report**: Invoices overdue by 30/60/90 days.
- **Tax Report**: Summary of VAT/GST collected.
