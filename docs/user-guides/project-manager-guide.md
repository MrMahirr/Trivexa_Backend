# Project Manager Guide

How to lead successful projects in Trivexa.

## 1. Project Setup

1.  **Create New Project**: Click the "+" button in the sidebar.
2.  **Basic Info**:
    - **Name**: "Website Redesign - Acme Corp".
    - **Client**: Select from list.
    - **Deadline**: Crucial for tracking delays.
3.  **Budget**: Set the total budget (e.g., $10,000) to track profitability.

## 2. Team Management

1.  Go to the **"Members"** tab.
2.  **Add Member**: Select users (Designers, Developers).
3.  **Assign Role**: `Member` (standard) or `Viewer` (read-only).

## 3. Task Planning

### 3.1 Creating Tasks
- Break down the project into actionable items.
- **Dependencies**: Use "Blockers" to ensure Task B cannot start before Task A finishes.

### 3.2 Milestones
- Group tasks into Milestones (e.g., "Phase 1: Discovery", "Phase 2: Development").
- Milestones help in tracking high-level progress.

## 4. Monitoring Progress

- **Board View**: Kanban style (To Do -> In Progress -> Review -> Done).
- **Gantt Chart**: Visualize timeline and dependencies.
- **Burndown Chart**: See if the team is on track to meet the deadline.

## 5. Client Updates

- **Share Deliverables**: Upload files to the "Deliverables" folder.
- **Request Approval**: The client gets a notification to approve/reject.
