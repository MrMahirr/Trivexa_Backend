# Designer Guide

Best practices for Design Team members using Trivexa.

## 1. Finding Your Work

1.  Go to **"My Tasks"**.
2.  Filter by Status: `In Progress` or `To Do`.
3.  Check the **Due Date** and **Priority** columns.

## 2. Asset Management

### 2.1 Uploading Files
- Navigate to the **"Assets"** tab within a Project.
- Drag & Drop your design files (Figma exports, PDFs, JPGs).
- **Naming Convention**: `[Project]_[Type]_[Version].ext`
    - *Example*: `Website_Homepage_v2.png`

### 2.2 Delivering Work
1.  Upload the final asset.
2.  Mark the Task as **"Review"**.
3.  Assign it to the Project Manager.

## 3. Time Tracking

Accurate time tracking is crucial for billing.

1.  Click the **"Start Timer"** button on the Task card.
2.  Or, manually log time at the end of the day:
    - Select Project > Select Task.
    - Enter Duration (e.g., `2h 30m`).
    - Mark as **Billable** (unless it's internal training).
